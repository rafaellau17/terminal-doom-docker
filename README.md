Esta investigación determinó la importancia y versatilidad de la contenerización virtual, más exactamente con Docker, teniendo en cuenta el gran tamaño y crecimiento del mercado de contenedores de aplicaciones. Se usó una primera investigación teórica, en la que se reafirmaron todos los conceptos que serían útiles para la posterior investigación aplicada. Toda esta investigación sería clave al momento de realizar el proyecto, el cuál fue un contenedor del videojuego clásico Doom. Para contenerizar, se usó el programa Docker, y VMware Workstation Pro 17, en el cual se virtualiza el sistema operativo Linux distro Ubuntu.
